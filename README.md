# decode

**decode** is a terminal **coding agent** ("agentic harness") you run in your terminal — a Pydantic-AI ReAct loop driving file/bash/web/MCP tools, with pluggable inference (Gemini / OpenRouter / Modal), local + remote sandboxing, Opik observability, and a Kitaru durability runtime, all behind a `prompt_toolkit` + `Rich` TUI.

This repository is an educational, open-source course that builds decode from scratch, step by step. It is a single Python package (`decode`); each module under `src/decode/` maps to one part of the architecture and is built in its own step.

**Start here:** [`AGENTS.md`](AGENTS.md) — conventions, architecture map, tech stack, and development workflow. Then `make install` and follow the steps.
